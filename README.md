# 工作日程面板

全员共用的项目周进度看板：帐号登录后，按任务分类查看每周进展，格子可在线编辑，并自动汇总本周工作。

## 启动

```bash
pip install -r requirements.txt
python app.py
```

浏览器打开 http://127.0.0.1:5000

演示帐号：`admin` / `admin123`  
同事可在登录页自行注册。

## 功能

- 帐号密码登录 / 注册
- 纵轴：任务分类 + 明细；横轴：周
- 点击格子填写进展，保存后记下编辑人和时间
- 色点循环标记：未填 / 进行中 / 已完成 / 受阻
- 可新增分类（带颜色标记）、新增任务
- 「周工作汇总」：本周每个任务的工作内容 + 个人进度记录
